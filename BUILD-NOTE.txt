KiraziumDungeons 1.1.5 UNIVERSAL 26.x

Target runtime:
- Paper 26.1.2
- Paper 26.2
- Paper 26.3 (current API line; pre-release/beta builds included)
- Dungeons+ 4.1.10
- Menus 1.9.2
- Nexo 1.28
- PhoenixCrates 6.0.0

Compatibility strategy:
1) Keep plugin.yml api-version at 1.21 so the same JAR can load on 26.1.2, 26.2, and 26.3.
2) Use the lowest common Bukkit/Paper API surface; no NMS/CraftBukkit implementation classes are used.
3) Runtime version reporting explicitly recognizes 26.1.2 / 26.2 / 26.3.
4) 26.3 is allowed; pre-release/beta deployments should be smoke-tested.
5) Unknown future versions are warned about but are not hard-disabled.

Preserved from 1.1.4:
- StageMonitor binary implementation
- Exact Nexo Item protection
- Phoenix key bridge
- Nexo GUI protection
- Phoenix LootChest visual bridge
- Dungeon glow
- Arrow remains removed
